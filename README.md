# 课序 · Kexu Timetable

一个本地优先、macOS 风格的课表工作台。所有样式、脚本和数据文件都在本目录中；课程数据直接写入本目录的 `data/timetable.json`，不使用 cookie，也不上传网络。

- 分周课表：每个教学周都有独立的节次时间与课程数据
- 连续节次：课程跨越两节、三节时，按起止时间自动合并成连堂卡片
- 批量设置：一次调整多个周的节次时间，或把一整周复制到其他周
- 课程个性化：名称、编号、批注、颜色、地点、教师、自定义起止时间
- iCal：支持 `.ics` 导入（含每周重复课程）与整套课表导出
- Obsidian 友好：批注支持 Markdown / `[[双链]]`，一键复制带 YAML frontmatter 的卡片
- 本地文件持久化：通过附带的本地小服务自动写入 `data/timetable.json`
- 效率工具：搜索全部课程、拖拽换课、跨周同步、快捷键、深色模式

## 启动（推荐）

课程数据需要写入文件夹，而浏览器出于安全限制不能直接写本地目录，因此项目附带了一个只监听本机的轻量服务（`server.py`，只用 Python 标准库）。

### macOS / Linux

双击 `start.command`，或在终端运行：

```bash
./start.sh
```

### Windows

双击 `start.bat`。

脚本会启动本地服务并自动打开浏览器，通常地址是：

```text
http://127.0.0.1:8765
```

如果 8765 端口被占用，会自动顺延到空闲端口，以终端打印的地址为准。

数据位置：

```text
calendar/data/timetable.json          课程数据
calendar/data/timetable.backup.json   自动保留的上一版
```

### 服务会一直运行吗？

- 关闭浏览器 **不会** 停止本地服务；服务在启动它的终端窗口中运行，方便下次直接打开。
- 关闭那个终端窗口，或在终端按 `Ctrl+C`，服务就会停止。也可以在另一个终端运行 `./stop.sh`（macOS 可双击 `stop.command`，Windows 双击 `stop.bat`）。
- 重复运行 `./start.sh` 不会启动第二个实例：脚本会检测已经运行的课序服务，直接打开浏览器。如果 8765 被其他程序占用，会自动换一个空闲端口。
- 停止服务不会动数据；`data/timetable.json` 仍在目录里，下次启动继续读取。

### 直接双击 index.html 会怎样？

可以浏览和编辑，但会进入 **临时模式**：数据只留在浏览器缓存中，**不会写入本目录**。界面顶部会持续显示提示。请在临时模式中先导出 JSON，或运行启动脚本后使用 **设置 → 数据 → 启用本地文件存储** 重新连接。

> 临时模式的数据属于当前浏览器来源。最稳妥的迁移方式是先在临时模式里导出 JSON，启动本地服务后，用 **设置 → 数据 → 从备份恢复** 导入。若浏览器来源与本地服务相同且目录里还没有数据文件，重试连接时会自动迁移；如果已有文件，则以目录中的文件为准。

## 第一次使用

首次通过本地服务打开会载入一份当前教学周（默认第 5 周）的示例课表，方便快速了解界面。点击提示条上的 **清除示例** 即可移除；也可以进入 **设置 → 数据 → 清空所有课程** 从空白开始。

默认学期从当前周往前第 4 周的周一开始、共 18 周、每天 8 个节次。可在 **设置 → 学期** 修改学期名称、开学日期和周数；在 **批量设置 → 节次时间与批量应用** 中调整每节课的起止时间。

### 自定义上课时间与连堂

每条课程默认跟随所在节次的时间。打开课程编辑面板里的 **自定义上课时间** 后，可以单独填写起止时间；保存时会自动把课程对齐到开始时间最接近的节次格，同时在卡片上保留原始起止时间。

连堂不需要手动指定“占几行”：课序会根据开始/结束时间以及当前周的节次表，自动判断这门课连续覆盖几个节次。例如第 1 节 `08:00–08:45`、第 2 节 `08:55–09:40`，录入 `08:00–09:40` 的课程就会占满两节；`14:00–16:45` 会连续占三节并显示为一张长卡片。

编辑面板里的 **连堂** 快捷按钮（`1 节` / `2 节` / `3 节` / `4 节`）可以按当前周的节次时间自动补全结束时间，适合快速录入两节或三节的课程。卡片上的 `2 节` 标记与底部节次范围会同步显示占用范围。

连堂是实时计算的：修改某一周的节次时间，或把课程复制到作息不同的周后，卡片占用节数会按该周的新时间自动重算，不需要单独维护“占几行”的字段。

### 不同教学周不同作息

节次时间按周独立保存在 `weeks[i].periods` 中。你可以只调整第 5 周的时间，不影响第 6 周；也可以一次选中多个周批量覆盖。课程会保留下来，并自动对齐到新的节次。

## iCal 导入

打开 **导入 iCal**，选择或拖入 `.ics` 文件：

- 解析 `VEVENT`、时区（`TZID` / UTC / 数字偏移）、`RRULE`（常用 `DAILY` / `WEEKLY` / `MONTHLY`）与 `EXDATE`
- 按事件日期映射到对应教学周，并按开始时间自动放入节次；跨多个节次的课程会自动形成连堂卡片
- 导入前显示范围、可导入数量、重复数量和预览
- 可选择导入整个学期，或只导入当前周；支持跳过重复日程
- 全天日程和学期外日程会跳过，并在界面中提示

可先用 [examples/demo-schedule.ics](examples/demo-schedule.ics) 体验导入。

导出路径：**设置 → 数据 → 导出 iCal**。导出生成的是每节课单独的 `VEVENT`，兼容 Apple 日历、Google Calendar、Outlook 等。

## 数据与隐私

- 文件模式下，课程数据直接写入 `data/timetable.json`；每次修改自动保存，并在覆盖前保留 `data/timetable.backup.json`。
- 本地服务的监听地址是 `127.0.0.1`，只接受本机请求；数据不会上传到网络。
- 不使用 cookie。文件模式也不会把课程数据写进 localStorage；如果当前浏览器来源下存在旧版 localStorage 数据且目录里还没有数据文件，第一次连接文件模式时会尝试迁移到文件，并清除旧的浏览器副本。
- 直接双击 `index.html` 的临时模式会使用浏览器缓存作为兜底，界面会明确标记；请尽快切换到文件模式。
- **设置 → 数据** 中会显示当前存储位置、数据大小，并提供完整 JSON 备份与恢复。
- Obsidian 卡片复制使用浏览器剪贴板 API；在较旧的浏览器中会回退到兼容方案。

## 技术说明

- 原生 HTML / CSS / JavaScript，无第三方依赖、无构建步骤、无 CDN。
- 本地服务使用 Python 标准库，只绑定 `127.0.0.1`；写入采用临时文件 + 原子替换，降低中断导致文件损坏的风险。
- 文件模式的数据结构就是完整 JSON，可直接用 JSON 备份恢复。
- 需要支持 `color-mix()`、`dvh` 和 backdrop-filter 的现代浏览器（Chrome / Edge 111+、Safari 16.2+）。
- 布局在桌面、窄窗口和手机上均可用；手机上时间表可横向滚动，并会自动定位到今天。
